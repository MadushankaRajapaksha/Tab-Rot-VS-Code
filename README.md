# Tab Rot Vs Code

A VS Code extenstion taht makes unused tabs showly look old with visuals

# What is Tab Rot?
Tab Rot helps you leave your screen with leave a file open without using it, its turn through these steps:
1. Faded
2. Grainy
3. Cracked
   
When u click an decayed tab, its flashes and become fresh again!

# How to Install
1. Download the file from [Github Release](https://github.com/MadushankaRajapaksha/Tab-Rot-VS-Code/releases/tag/v1.0.1). 
2. Open VS Code App
3. Press `CTRL + SHIFT + P` in Windows or `CMD + SHIFT + P` in Mac.
4. Type `Extension: Install from VSIX` and pick downloded file.

# Settings
1. Press `CTRL + SHIFT + P` in Windows or `CMD + SHIFT + P` in Mac
2. Type `Tab Rot: Show Tab Rot Settings` and hit Enter Then Open Window of Settings!
   
# Commands

Press Ctrl + Shift + P and search for:
- **Tab Rot: Restore Tab** — Fixes your current tab.
- **Tab Rot: Restore All Tabs** — Fixes all open tabs.
- **Tab Rot: Show Decayed Tabs** — Opens the side list of old tabs.
- **Tab Rot: Show Tab Rot Settings** - Opens Settigs

📌 Note: By default, after installation, the decay times are set to 1 min, 2 mins, and 3 mins so you can see it working quickly. Please change these settings to your own custom times after installing!
